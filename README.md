# Кинония — сайт занятий и запись

Мини-сайт духовно-просветительского центра «Кинония» при храме Живоначальной Троицы на Сходне: каталог 18 занятий, расписание недели и онлайн-запись. Заявки собираются в Google-таблицу и приходят администратору в Telegram.

## Как это работает

```
Сайт (форма) ──┐
               ├──► Google Apps Script ──► Google-таблица «Заявки»
Telegram-бот ──┘          │
 (каталог + запись)       └──► сообщение администратору в Telegram
                                 [📞 Связались] [✅ Записан] [✖ Отказ]
                                        │
                     статус пишется в таблицу, а записавшийся через бота
                     получает сообщение «Вы записаны»
```

- **Пока сервер не подключён**, форма сайта открывает WhatsApp администратора с готовым текстом заявки. Сайт полезен с первого дня.
- **Бот** показывает каталог по направлениям, карточку каждого занятия и принимает запись прямо в чате: имя → кто будет заниматься → номер одной кнопкой.
- **Таблица** — журнал всех заявок с цветными статусами: «Новая», «Связались», «Записан», «Отказ». Статус можно менять и в таблице вручную.

## Подключение (один раз, ~10 минут)

1. Создайте новую Google-таблицу, например «Кинония — заявки».
2. В таблице: **Расширения → Apps Script**. Удалите всё в редакторе и вставьте содержимое файла `backend/Code.gs`.
3. В начале файла впишите токен бота в `BOT_TOKEN_INIT = "..."` (токен выдаёт @BotFather) и адрес сайта в `SITE_URL_INIT`.
4. **Начать развертывание → Новое развертывание → Тип: Веб-приложение.**
   Выполнять от имени: «Я». Доступ: **«Все»**. Нажмите «Развернуть» и разрешите доступ к таблице.
5. Вверху редактора выберите функцию **`setup`** и нажмите **«Выполнить»**. В журнале появятся:
   - адрес веб-приложения — вставьте его в `js/config.js` в поле `endpoint`;
   - имя бота — вставьте в `botUsername`;
   - **код администратора**.
6. Напишите боту в Telegram: `/admin КОД`. С этого момента заявки приходят в этот чат. Так можно подключить несколько человек или целую группу. Отключиться: `/admin_off`.
7. Очистите строку `BOT_TOKEN_INIT` в скрипте: токен уже сохранён в свойствах скрипта.

> Если поменяете код скрипта, сделайте **Развертывание → Управление → Изменить → Новая версия**, иначе изменения не применятся.

## Как менять занятия

Все занятия лежат в `js/clubs.js`: название, педагог, расписание, описание, пожертвование. Сайт перестраивается сам: каталог, фильтры, неделя, форма.

Для бота каталог продублирован в конце `backend/Code.gs` (блок `CLUBS`). После правок `clubs.js` обновите и его.

## Оформление

Сайт сделан в стиле официального сайта храма shodnyahramnew.ru: те же шрифты, цвета (красный #A12F2F, охра #AD731D) и фотографии. Чтобы поменять фото занятия, положите файл в `img/` и укажите его в поле `photo` в `clubs.js`.

Шрифт Lovelace — пробная версия с сайта храма: цифры в ней заменены штампом TRIAL, поэтому сайт берёт цифры из Georgia. Если купить полную версию, уберите строку `unicode-range` в начале `css/style.css`.

## Полезное

- Ссылка, которая сразу открывает форму на нужном занятии: `…/#zapis=icon` (id занятия смотрите в `clubs.js`).
- Ссылка на карточку занятия с описанием: `…/#kruzhok=icon`.
- Ссылка на карточку занятия в боте: `https://t.me/ИМЯ_БОТА?start=c_chess`.
- Защита от спама: скрытое поле-ловушка и не больше 3 заявок с одного номера за 10 минут.
- Персональные данные хранятся только в вашей Google-таблице.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Страница |
| `css/style.css` | Оформление |
| `js/clubs.js` | **Все занятия — правьте здесь** |
| `js/config.js` | Адрес сервера, имя бота, контакты администратора |
| `js/app.js` | Логика: каталог, карточки, фильтры, неделя, форма |
| `img/` | Фотографии занятий (`<id>.jpg`), логотип, обложка |
| `fonts/` | Шрифты сайта храма: Lovelace (заголовки) и TildaSans (текст) |
| `backend/Code.gs` | Сервер: таблица и Telegram-бот (вставляется в Apps Script) |
